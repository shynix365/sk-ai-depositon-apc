> **한 줄 결론** — 이 데이터의 보정량 라벨은 잡음이 아니라 결정론적 제어식이다.

## 1. 문제 정의

증착 공정은 같은 레시피로 돌려도 챔버 상태가 변하면 두께가 달라진다(**run-to-run drift**).
현장 Run-to-Run APC 는 `run k` 의 계측 결과로 `run k+1` 의 사이클 수를 보정하는데,
**계측이 표본 검사**라 측정되지 않은 run 은 보정 없이 흘러간다.

이 과제가 답하려는 질문은 세 가지다.

| # | 질문 | 답 | 근거 |
|---|---|---|---|
| Q1 | 드리프트가 실제로 있는가, 있다면 무엇 때문인가 | 있다. **챔버 누적런**이 유일한 원천 | 불균일도 R²=0.896, 두께 +0.0189 nm/run |
| Q2 | 계측 없이 다음 run 의 보정 여부를 판단할 수 있는가 | 조건부로 가능 | 두께 R²=0.913, ESCALATE AUC 0.938 |
| Q3 | 판단하면 안 되는 구간은 어디인가 | 예측구간이 판정 경계를 걸치는 **59%** | 공형예측 q₉₀=2.06 nm vs HOLD 밴드 0.42 nm |

## 3. 복원한 공정·제어 구조

```
두께      t = 0.2152·N + 0.0189·age + 0.0790·T + 0.0276·Q + tool_j        R²=0.916, σ=1.26 nm
불균일도   U = 1.5256 + 0.011726·age                                       R²=0.896, σ=0.275 %
면저항     ln R = 9.95 − 1.390·ln t                                        R²=0.826
보정량     Δ = clip( −(t − 70.0) / 0.21 , −12, +12 )                       R²=1.0000000
```

마지막 식이 이 분석의 핵심이다. 비포화 구간 271행으로 회귀하면 **R² = 1.000000, 최대 절대잔차 2.9×10⁻⁶ cycle** —
목표 두께 `T* = 70.0 nm`, 공칭 `GPC = 0.21 nm/cycle`, 클램프 `±12 cycle` 이 정확히 떨어진다.

> **그래서 문제가 재정의된다.** 보정량을 ML로 예측하는 것은 이미 알려진 함수를 근사하는 낭비다.
> 진짜 불확실한 것은 **계측 전에 두께를 아는 것**(가상계측)이고, 보정량은 거기서 결정론적으로 따라온다.

## 5. 결과

### 5.1 회귀 (7:3 랜덤 분할, seed 42 · 학습 563 / 검증 242)

| 타깃 | 최우수 모델 | 검증 R² | 검증 RMSE | 해석 |
|---|---|---|---|---|
| 두께 (nm) | Huber (로버스트) | **0.9135** | 1.314 | 목표 70 nm 대비 1.9% 오차 |
| 불균일도 (%) | Lasso (L1) | **0.9084** | 0.255 | 누적런 하나로 거의 결정 |
| 면저항 proxy | 선형회귀 (OLS) | **0.8056** | 2.738 | 두께의 종속변수 |
| 보정량 (cycle) — 직접 | ExtraTrees | 0.8724 | 3.403 | 클램프 계단을 트리가 흉내 |
| 보정량 (cycle) — **물리결합** | 선형 두께모델 → 제어식 | **0.9128** | **2.812** | **RMSE −17.4%, MAE −34.9%** |

**선형 모델이 전 타깃에서 1위다.** 생성식이 선형이므로 물리적으로 옳은 결과이며,
모델을 크게 만들 이유가 없다는 근거다(HistGB 학습 R² 0.996 → 검증 0.877, 전형적 과적합).

### 5.2 보정 판정 (3-클래스)

임계는 임의값이 아니라 물리량에서 유도했다.

- **HOLD** \|필요보정\| ≤ 2 cycle (= 두께 오차 ±0.42 nm, 계측 반복성 수준)
- **ADJUST** 2 < \|필요보정\| ≤ 12 cycle (제어기가 한 번에 되돌릴 수 있는 범위)
- **ESCALATE** \|필요보정\| > 12 cycle (클램프 초과, 엔지니어 개입)

| 판정기 | 정확도 | 균형정확도 | macro F1 | HOLD F1 | ESCALATE F1 |
|---|---|---|---|---|---|
| **물리결합 (두께 예측 → 제어식 → 임계)** | **0.814** | **0.625** | **0.613** | **0.250** | **0.893** |
| 직접 분류 · RandomForest(balanced) | 0.810 | 0.546 | 0.531 | 0.000 | 0.869 |
| 직접 분류 · HistGB | 0.764 | 0.493 | 0.492 | 0.000 | 0.848 |
| 직접 분류 · GradientBoosting | 0.764 | 0.484 | 0.483 | 0.000 | 0.843 |
| 직접 분류 · 로지스틱(balanced) | 0.612 | 0.382 | 0.411 | 0.000 | 0.781 |

직접 분류기는 **전부 HOLD F1 = 0** 이다. 정확도만 보면 비슷하지만 소수 클래스를 아예 포기했다.

### 5.3 불확실성 인지 정책 — 이 프로젝트의 실질적 성과

HOLD 밴드 반폭 **0.42 nm** vs 두께 예측 90% 구간 반폭 **2.06 nm** → 밴드가 오차보다 **4.9배 좁다**.
모델을 아무리 좋게 만들어도 넘을 수 없는 벽이므로, **판정을 유보하는 능력**을 모델에 넣었다.

분할 공형예측(split conformal, Lei et al. 2018)으로 두께에 예측구간을 붙이고,
그 구간이 판정 경계를 걸치면 자동 판정 대신 **실측 요청**을 낸다.

| 정책 | 자동 판정 비율 | 자동 판정분 정확도 |
|---|---|---|
| 전건 자동 판정 | 100% | 81.4% |
| **유보 정책 적용** | **41.3%** | **96.0%** |

→ 운영 번역: **전체 run 의 41%를 계측 없이 자동 처리하고 오판율은 4%**, 나머지 59%만 계측한다.

### 5.4 Holdout 200행

| 판정 | 건수 | 비율 |
|---|---|---|
| ESCALATE | 123 | 61.5% |
| ADJUST | 66 | 33.0% |
| HOLD | 11 | 5.5% |
| 자동 판정 가능 | 88 | 44.0% |

- KS 검정 6개 입력 전부 p>0.05 → **공변량 이동 없음**, 학습 모델 그대로 적용 가능
- 예측 평균 두께 **67.27 nm** (목표 70.0 nm 대비 −2.7 nm)
- ESCALATE 가 61.5%인 것은 개별 run 문제가 아니라 **공칭 레시피가 낮게 세팅**되어 있다는 신호
- 불균일도 4% 초과 예상 **23건** → 해당 챔버 PM 대상

산출: `outputs/holdout_predictions.csv`

## 6. 공정 지식 기반 해석

| 발견 | 물리 해석 | 근거 |
|---|---|---|
| GPC 가 누적런과 함께 **+19%** 상승 | 챔버 벽 축적막이 전구체 흡착·재방출과 복사 열전달을 바꿔 성장속도 증가 | 평균 조건 두께 65.6 → 70.1 nm (age 0→240) |
| 온도 감도 **0.32 %/℃**, 겉보기 Ea ≈ **0.12 eV** | CVD 열분해 율속(1–2 eV)보다 한 자릿수 낮음 → **표면반응 포화 ALD-like 창** 안에서 동작 | Ea = R·T²·(1/GPC)(dGPC/dT) |
| log–log 기울기 **−1.390** (이상값 −1) | 초과분 −0.39 = 비저항의 두께 의존. 표면 산란(Fuchs–Sondheimer) + 입계 산란(Mayadas–Shatzkes) | 두께 10% 감소 → 면저항 약 15% 상승 |
| 불균일도 3%/4% 교차 = **126 / 211 run** | 사이클 보정으로 되돌릴 수 없는 열화 → **PM 주기의 정량 근거** | 사이클 계수 0.0002 (p=0.71) |
| 제어기 공칭 GPC 0.21 vs 실제 0.2152 | **2.5% 낮게 잡혀 구조적 미달 보정**. 누적런이 쌓이면 격차 확대 | 두께 모델 사이클 계수 |
| 클램프 포화 **63.6%** | 되먹임 이득이 사실상 0. 답은 클램프 확대가 아니라 **레시피 재센터링(+10 cycle)** | 평균 두께 67.9 vs 목표 70.0 nm |

## 7. 한계 · 적용 금지 조건

1. **HOLD/ADJUST 경계 판정** — 밴드(0.42 nm)가 예측구간(2.06 nm)보다 좁다. 유보 정책 필수.
2. **\|필요보정\| > 12 cycle** — 한 run 으로 복귀 불가. 자동 보정이 아니라 알람 대상.
3. **챔버 누적런 > 211** — 불균일도 스펙 초과. 사이클 보정으로 해결되지 않는 열화.
4. **학습 범위 밖 외삽** — 온도 362–409℃, 사이클 80–140, 누적런 0–240 밖은 미보증.
5. **T05 등 소표본 장비** — 46건뿐이라 tool 오프셋 추정이 불안정.
6. **계측 지연이 데이터에 없다** — 실제 R2R 의 dead-time 보상은 검증하지 못했다.
7. **λ(EWMA 이득)를 실증할 수 없다** — 라벨이 전이득(λ=1) 데드비트 제어라 λ<1 효과는 시뮬레이션 영역.
8. **면저항 잔차 4.1% 미설명** — 결정립·조성·표면거칠기 데이터가 있으면 MS 모형으로 분해 가능.
9. **회귀 진단 일부 기각** — Jarque–Bera p<0.001, Breusch–Pagan p=0.0002.
   계수의 불편성이 아니라 표준오차의 문제이며, Huber 회귀가 OLS와 동일 성능(0.9135 vs 0.9133)을 낸 것으로 강건성을 확인했다.
